# Adams UPS pilotu

Python backend ve HTML/CSS/JavaScript ekranından oluşan yerel UPS test uygulaması. Python 3.10+ ve güncel bir tarayıcı yeterli; ek paket kurulumu gerekmiyor.

Uygulamanın özeti, iş kuralları ve çalıştırma bilgileri [kullanım notunda](shipping_pilot/SEZGIN-DEVIR.md); teknik ayrıntılar [README.md](shipping_pilot/README.md) dosyasında yer alıyor.

Credentials pakete dahil değil. Form ve otomatik testler credentials olmadan çalışıyor; UPS fiyat/label çağrıları için ayrı yapılandırma gerekiyor.
